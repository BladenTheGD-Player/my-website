CLEAN MATRIX PERSONAL WEBSITE
=============================

FILES
-----
index.html   Website content and structure
style.css    Clean Matrix visual design and responsive layout
script.js    Subtle animated background and mobile navigation

PREVIEW LOCALLY
---------------
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.

PUBLISH WITH GITHUB PAGES
-------------------------
1. Sign in to GitHub and create a new repository.
2. For a personal root website, name the repository:
      YOUR-USERNAME.github.io
   Or use any repository name for a project website.
3. Upload index.html, style.css, and script.js to the repository's
   top-level folder (not inside another folder).
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and the /(root) folder, then Save.
7. Wait for GitHub Pages to publish your website.

PERSONALISE IT
--------------
Search index.html for:
- YOUR NAME
- [Your name]
- hello@example.com
- Your project titles and descriptions
- Social links / interests

Replace these placeholders with your own details. The project cards
currently include REX.PY as an example based on your project.

NOTES
-----
- No build tools or frameworks are required.
- The Matrix background is drawn locally with JavaScript.
- Google Fonts are loaded from the internet; system fonts are used
  if they cannot be reached.
- GitHub Pages is static hosting: this site does not include a
  server-side contact form or private database.
